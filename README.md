# sns-connect

Instagram のビジネスログイン（OAuth）の戻り先として使う、受け取り専用の1ページです。

## これは何をするページか

- Instagram の承認画面で「許可」を押した後に着地する画面です。
- URL に付いてくる連携コード（`?code=...`）を**画面に表示するだけ**のページです。
- コードはブラウザ内でしか扱いません。**サーバーへ送信も保存もしません**（このリポジトリに動くサーバーはありません）。

## なぜローカルの戻り先にしないのか

戻り先を `localhost` にすると、承認した方の端末で「接続できません」というエラー画面が出ます。
コード自体はアドレスバーに入っているのですが、そこから手で切り出していただく形になり、
操作に慣れていない方には確実に詰まります。このページはその1点だけを解決します。

## 使い方

1. Meta アプリのリダイレクトURIに、このページのURLを登録する
2. 承認用リンクを発行して相手に渡す
3. 相手が「許可」を押すと、このページにコードが表示される
4. そのコードを受け取り、アクセストークンと交換する

## 構成

- `index.html` … 単一ファイル。外部リソースへの依存なし。
